Features

Everything An Exam Needs, Start To Finish

Xamlysis covers the whole cycle — scheduling a paper, getting students registered, running the timed attempt, grading it, and turning the result into something a student can actually learn from.

For Teachers

Build A Paper Once, Reuse The Structure

Set the exam code, title, date, start time and duration, then attach it to a course and a class. Students in that class who are enrolled in that course see it automatically — there is no separate invite step.

  • Question authoring — four options per question, one correct answer, individual marks.
  • Paper status — the schedule shows Ready or Incomplete so you never open an unfinished exam.
  • Registration counts — see how many students have signed up before the day.
  • Class performance — average, highest and lowest percentage per exam.
  • Student queries — questions raised against an exam reach you directly.

For Students

Know What Is Coming, And How You Did

Pick your class, enrol in your courses, and your exam list fills itself in. Register ahead of the date, attempt the paper when it opens, and get your score the moment you submit.

  • Scheduled view — every upcoming exam with date, duration and marks.
  • One-tap registration — register early so the exam is ready on the day.
  • Instant grading — marks and percentage calculated on submit.
  • Answer review — see each question with your answer beside the correct one.
  • Private notes — keep your own revision notes against any exam.

Under The Hood

The details that make the day-to-day work predictable.

Class And Course Scoping

An exam reaches a student only when both the class and the course match, so nobody sees a paper meant for another group.

Per-Question Marks

Questions carry their own weight. A five-mark definition and a twenty-mark derivation sit in the same paper.

Randomised Order

Question order is shuffled on each attempt, which makes casual copying considerably harder.

Timed Attempts

Each exam carries a duration. The attempt page tracks it so pacing becomes part of the practice.

Role-Based Views

One account, one role. Teachers and students get entirely different dashboards from the same login.

Admin Console

Django's admin at /admin/ exposes every table for bulk edits and corrections.

See It With Real Data

The demo database ships with six courses and seven exam papers already loaded.
